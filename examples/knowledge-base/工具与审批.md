# 工具与审批

MiniC 内置多类工具，按权限分类，写操作需要审批。

## 只读工具

工作区内自动放行，无需审批：

- `Read`：读取文件
- `ReadMemory`：按主题读取长期记忆
- `TextSearch`：全文搜索
- `Lint`：Python 语法检查
- `GitStatus` / `GitDiff` / `GitLog`：查看 Git 状态、差异、日志

## 写工具

执行前需要审批，先备份再执行，可回滚：

- `Write`：写文件
- `Edit`：增量编辑
- `Format`：格式化文件
- `GitCommit` / `GitBranch`：提交改动、新建分支

审批支持四种决策：

- `allow_once`：本次放行，不落盘
- `allow_session`：当前会话放行，不落盘
- `allow_always`：写入 `permissions.json` 持久化
- `deny`：拒绝执行，且优先于 `allow_always`

## Bash

执行终端命令，**必须人工审批**，审批菜单只提供 `allow_once` / `deny`；命令输出会做 PII 脱敏（API Key、手机号等）。

## MCP 工具

接入的外部 MCP 工具以 `server_name.tool_name` 命名，配置在 `~/.minic/mcp/minic_mcp_settings.json`；`autoApprove` 列表内的工具免审批，其余走现有审批流程。
