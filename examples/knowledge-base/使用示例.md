# 使用示例

以下示例演示用 MiniC 完成一个本地知识库问答任务。

## 1. 入库

把本目录（`examples/knowledge-base/`）中的 Markdown 文件入库：

```powershell
minic ingest .\examples\knowledge-base
```

入库是增量且幂等的：重复执行同一目录会全部跳过，只入库变化的文件。

## 2. 单次检索

```powershell
minic query "MiniC 的默认模型是什么" --top-k 5
```

输出会列出命中的文件路径、章节、分数与内容摘要。

## 3. 交互式问答

```powershell
minic chat --path .\examples\knowledge-base
```

首次提问会自动完成入库，然后进入会话。可以连续追问，例如：

- 先问：MiniC 支持哪些本地工具？
- 再追问：它们需要审批吗？

追问会结合会话上下文自动改写查询，命中更准确。

## 4. 查看来源

回答结束后会以独立来源块展示 `文件路径 + 章节`，方便核对答案出处。

## 说明

- 本示例只是演示功能，示例文件内容与 MiniC 项目相关。
- 使用真实知识库时，把路径换成你的 Markdown 文件夹即可；Obsidian 知识库同样支持。
